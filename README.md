# myAlarm（シフトアラーム）

交代勤務（日勤・夜勤など）向けの個人用 iOS アラームアプリです。
「日勤」「夜勤」のようなアラームのセットを**テンプレート**として持っておき、ワンタップで一括切り替えしたり、日付ごとに使うテンプレートを**予約**したりできます。

## 主な機能

- **テンプレート**: 複数のアラーム（時刻・ラベル・オン/オフ）をまとめたセット。名前と色を設定できます。既存のテンプレートをコピーして作ったり、他のテンプレートのアラームを取り込んだりできます。
- **時間帯でまとめて追加**: 開始時刻〜終了時刻を指定した分おきに、アラームをまとめて追加できます（テンプレートとこの日だけのアラームの両方）。
- **選択して削除**: テンプレートのアラームやこの日だけのアラームを、選択モードでまとめて削除できます。
- **起きた（一括停止）**: 鳴っているアラームの「起きた」ボタン、または予定タブの「起きた」で、続けて鳴る予定のアラーム（間隔 60 分以内で連なるもの）をまとめて止めます。「元に戻す」で取り消せます。
- **ラベルをまとめて設定**: テンプレートやその日のアラームのラベルを、すべて、または空欄のものだけまとめて設定できます。
- **基本テンプレートの一括切り替え**: 予約がない日に使うテンプレートを 1 つ選びます（「なし」も選択可）。
- **カレンダー**: 月表示のカレンダーで、各日に使われるテンプレートを確認できます。日付をタップするとその日の編集シートが開きます。
- **日ごとの予約**: 特定の日だけ別のテンプレート、または「休み（アラームなし）」を指定できます。
- **まとめて設定**: 週・月・期間を選んで、同じテンプレート、繰り返しパターン（例: 日日夜夜休休）、曜日指定（例: 月〜金は日勤）でまとめて予約できます。
- **この日だけのアラーム**: テンプレートとは別に、特定の日だけ鳴る単発アラーム（時刻・ラベル）を追加できます。

その日に使うテンプレートは **予約 > 基本テンプレート** の優先順で決まります。単発アラームはテンプレートのアラームに加えて鳴ります。

## しくみ

iOS では、アプリが指定日に自分で「テンプレートを切り替える」処理を確実に実行することはできません。
そのため、**今日から 14 日先までの日付指定アラームを AlarmKit にまとめて登録しておく**方式にしています。

- データを変更したとき、アプリを開いたときに、登録済みのアラームをすべて取り消して登録し直します。
- バックグラウンド更新（BGAppRefreshTask）でも、登録範囲を先へ延長します。
- 14 日以上アプリを開かず、バックグラウンド更新も走らなかった場合は、それより先のアラームは登録されません。

## 動作環境

- iOS 26.0 以上（AlarmKit を使用）
- Xcode 26 以上
- 外部ライブラリなし（SwiftUI / SwiftData / AlarmKit / BackgroundTasks）

## ビルドと実行

1. `myAlarm.xcodeproj` を Xcode で開きます。
2. ターゲット `myAlarm` の Signing & Capabilities で自分の Team を選びます。
3. 実機を選んで実行します。初回起動時にアラームの許可を求められます。

初回起動時には「日勤」「夜勤」のサンプルテンプレートが作成されます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `myAlarm/MyAlarmApp.swift` | エントリポイント。SwiftData のコンテナ作成、同期とバックグラウンド更新の起動 |
| `myAlarm/Models.swift` | SwiftData モデル（`AlarmTemplate` / `TemplateAlarm` / `ShiftReservation` / `OneOffAlarm`）、予約の書き込み、サンプルデータ |
| `myAlarm/AlarmPlanner.swift` | 日ごとにどのアラームが鳴るかを計算する純粋なロジック |
| `myAlarm/AlarmScheduler.swift` | 計算結果を AlarmKit に登録・同期する |
| `myAlarm/ContentView.swift` | タブ構成と、データ変更を検知して同期を依頼する処理 |
| `myAlarm/ScheduleView.swift` | 「予定」タブ（次のアラーム、基本テンプレート切り替え、月カレンダー） |
| `myAlarm/DayDetailSheet.swift` | 1 日分の編集シート（テンプレートの予約、この日だけのアラーム） |
| `myAlarm/BulkApplySheet.swift` | 週・月・期間へのまとめて設定 |
| `myAlarm/BulkAlarmInputSheet.swift` | 時間帯を指定したアラームのまとめて追加 |
| `myAlarm/TemplateViews.swift` | 「テンプレート」タブ（テンプレートとアラームの編集） |
